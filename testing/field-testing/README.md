# Hospitality Flow – Field Testing Principles

## Purpose

This folder is used to collect findings from real hotel operations. The goal is to improve Hospitality Flow using evidence from live shifts rather than assumptions.

## Principles

- Test Hospitality Flow in real hotel environments.
- Record observations instead of immediately fixing them.
- Prioritise operational accuracy over AI creativity.
- Prefer fewer, highly accurate outputs rather than detailed but incorrect information.
- Test using realistic, messy handovers and real operational scenarios.
- Focus on helping reception teams work faster, communicate better, and reduce operational mistakes.
- Review and prioritise findings weekly before starting development.

## Development Workflow

After each shift:

- Record bugs.
- Record improvements.
- Record new ideas.

At the end of each week:

- Review all findings.
- Remove duplicates.
- Prioritise by operational impact.
- Create a development plan.
- Implement the highest-value improvements first.

## Core Philosophy

Hospitality Flow should think like an experienced Hotel Duty Manager, not simply rewrite text.

When confidence is low, it is better to preserve the original information or produce a shorter, more accurate result than to generate confident but incorrect conclusions.
