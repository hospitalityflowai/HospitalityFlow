# Pilot Hotel

## Overview

Pilot Hotel is Hospitality Flow's permanent fictional testing property.

It is an independent boutique hotel in London. Every scenario in this suite should assume this same hotel profile unless the scenario file states otherwise.

## Property

| Attribute | Value |
|-----------|-------|
| Name | Pilot Hotel |
| Type | Independent boutique hotel |
| Location | London |
| Rooms | 80 |
| Reception | Open 24/7 |

## Facilities and departments

- Restaurant
- Bar
- Room service
- Meeting room
- Concierge
- Housekeeping
- Maintenance
- Night manager

## Guest mix and products

- Mixed leisure and business guests
- Regular VIP guests
- Airport transfers
- Wake-up calls
- OTA bookings
- Corporate accounts
- Long-stay guests

## Usage notes

- Use this profile as the fixed operational context for Scenarios 001 onwards.
- Do not invent a different property size, location, or department list unless a scenario explicitly overrides a detail.
- Keep room numbers, guest names, and commercial details consistent with an 80-room London boutique hotel when scenario data is later filled in.
