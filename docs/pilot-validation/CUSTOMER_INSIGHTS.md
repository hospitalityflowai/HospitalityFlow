# Hospitality Flow Customer Insights

Store direct evidence from hotel users without rewriting their meaning.

## Rules

- Record direct quotes as closely as possible.
- Do not improve or reinterpret the participant’s wording.
- Separate observation from interpretation.
- Never record sensitive guest information.
- Use roles rather than unnecessary personal details.
- Link each insight to a pilot session or date.
- Mark whether it is a one-off comment or repeated pattern.

## Emerging Patterns

_Add patterns only when the same signal appears across sessions. Keep wording close to source evidence._
