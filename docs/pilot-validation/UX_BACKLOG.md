## Backlog Decision Rules

An item should normally be approved when at least one applies:

1. Multiple independent users report the same problem.
2. It blocks completing a core workflow.
3. It creates incorrect operational understanding.
4. It materially reduces trust.
5. It saves meaningful time with low implementation risk.

Cosmetic preference alone should not outrank operational clarity.
